# Graph Algorithms and Dynamic Programming

This project is part of the **Graph Algorithms and dynamic Programming (DP)** course at the **National Polytechnic University of Armenia (NPUA)**.

---

| File                      | Description                                                                   |
|---------------------------|-------------------------------------------------------------------------------|
| [BFS.py](https://github.com/MariHovhannisyan/Algorithms_and_DataStructures/blob/master/Midterm%201/BFS.py)            | Breadth-First Search (BFS) algorithm for traversing graphs.                  |
| [DFS.py](https://github.com/MariHovhannisyan/Algorithms_and_DataStructures/blob/master/Midterm%201/DFS.py)             | Depth-First Search (DFS) traversal implementation.                           |
| [Dijkstra's.py](https://github.com/MariHovhannisyan/Algorithms_and_DataStructures/blob/master/Midterm%201/Dijkstra's.py)| Dijkstra's algorithm for shortest paths using a lazy priority queue approach.|
| [BellmanFord.py](https://github.com/MariHovhannisyan/Algorithms_and_DataStructures/blob/master/Midterm%201/BellmanFord.py)| Bellman-Ford algorithm for shortest paths, with negative cycle detection.    |
| [FloydWarshall.py](https://github.com/MariHovhannisyan/Algorithms_and_DataStructures/blob/master/Midterm%201/FloydWarshall.py)| Floyd-Warshall algorithm for all-pairs shortest paths.                       |
| [Kahn's.py](https://github.com/MariHovhannisyan/Algorithms_and_DataStructures/blob/master/Midterm%201/Kahn's.py)       | Kahn's algorithm for topological sorting using in-degrees.                   |
| [TopSort.py](https://github.com/MariHovhannisyan/Algorithms_and_DataStructures/blob/master/Midterm%201/TopSort.py)     | DFS-based Topological Sorting implementation.                                |
| [Longest_path.py](https://github.com/MariHovhannisyan/Algorithms_and_DataStructures/blob/master/Midterm%201/Longest_path.py)| Finds the longest path in a Directed Acyclic Graph (DAG).                   |
| [connected_components.py](https://github.com/MariHovhannisyan/Algorithms_and_DataStructures/blob/master/Midterm%201/connected_components.py)| Identifies connected components in an undirected graph.                    |
| [Dungeon.py](https://github.com/MariHovhannisyan/Algorithms_and_DataStructures/blob/master/Midterm%201/Dungeon.py)     | Finds the minimum steps to navigate a maze from start ('S') to end ('E').    |
| [DP_Factorial.ipynb](https://github.com/MariHovhannisyan/Algorithms_and_DataStructures/blob/master/Midterm%202/DP_Factorial.ipynb)                        | Computes factorial using dynamic programming (bottom-up and top-down).       |
| [DP_Fibonacci.ipynb](https://github.com/MariHovhannisyan/Algorithms_and_DataStructures/blob/master/Midterm%202/DP_Fibonacci.ipynb)                        | Solves Fibonacci numbers with recursion, memoization, and DP table.          |
| [DP_Knapsack.ipynb](https://github.com/MariHovhannisyan/Algorithms_and_DataStructures/blob/master/Midterm%202/DP_Knapsack.ipynb)                          | 0/1 Knapsack problem using dynamic programming approach.                     |
| [DP_MagicalCows.ipynb](https://github.com/MariHovhannisyan/Algorithms_and_DataStructures/blob/master/Midterm%202/DP_MagicalCows.ipynb)                    | Solves a DP problem involving magical cows (growth over days).               |
| [Redundant_Connection.ipynb](https://github.com/MariHovhannisyan/Algorithms_and_DataStructures/blob/master/Midterm%202/Redundant_Connection.ipynb)         | Detects and removes an extra edge to convert a graph to a tree.              |
| [Find_centre_of_star_graph.ipynb](https://github.com/MariHovhannisyan/Algorithms_and_DataStructures/blob/master/Midterm%202/Find_centre_of_star_graph.ipynb)| Identifies the center node in a star-shaped undirected graph.                |
| [Find_if_path_exists_in_a_graph.ipynb](https://github.com/MariHovhannisyan/Algorithms_and_DataStructures/blob/master/Midterm%202/Find_if_path_exists_in_a_graph.ipynb)| Checks if a path exists between two nodes in an undirected graph.            |
| [Jump_game.ipynb](https://github.com/MariHovhannisyan/Algorithms_and_DataStructures/blob/master/Midterm%202/Jump_game.ipynb)                              | Solves the Jump Game problem for minimum jumps to reach the end.             |
| [Target_Sum.ipynb](https://github.com/MariHovhannisyan/Algorithms_and_DataStructures/blob/master/Midterm%202/Target_Sum.ipynb)                            | Finds the number of ways to assign + and - to reach a target sum (DP/Backtracking).|
| [Best_time_to_buy_and_sell_stock.ipynb](https://github.com/MariHovhannisyan/Algorithms_and_DataStructures/blob/master/Midterm%202/Best_time_to_buy_and_sell_stock.ipynb)| Solves multiple stock buy-sell profit problems (easy, medium, hard).         |
